# AgentProof.cloud — 商业价值最大化方案（2026-11-11）

> 结论：**未来 90 天不要把精力放在 SaaS 订阅上，先做“产品化安全审计服务”**。
> 开源仓库 + 免费扫描器负责获客，人工审计按次收钱，SaaS 订阅等有 3 个付费客户后再上。

## 1. 为什么不先做 SaaS

| 现实 | 后果 |
|---|---|
| 没有支付通道（Stripe/LemonSqueezy 需要 KYC） | $99/$1,500 的价目表目前只是装饰 |
| 没有公网后端（Railway/Render 需要账号） | 客户注册后拿不到真 API |
| 没有品牌、没有案例、没有第三方背书 | 企业不会为“合规证据”预付年费 |
| 单人维护、代码主要是 AI 生成 | 大客户采购/安全评审过不了 |
| “AI Act 合规”是法律高门槛表述 | 越像认证，越容易踩法律与信任雷 |

→ 继续堆 SaaS 功能，每多一行代码，边际收入接近 0。
→ **按次审计**没有这些问题：不需要支付基础设施、不需要多租户后端、不需要品牌年费信任，交付物就是文件。

## 2. 产品阶梯与定价

| 层级 | 价格 | 交付 | 目标客户 |
|---|---|---|---|
| 免费扫描 | $0 | 网页 A–F 评级 + 修复建议 + policy.yaml | 所有访客，进邮件列表 |
| **Quick Audit** | **$490 / 次** | 1 个仓库或 1 份 mcp.json + 工具代码；48h 交付签名审计报告（HTML/PDF）、修复清单、默认拒绝策略；1 轮邮件答疑 | 种子轮–A 轮 AI 团队、MCP server 作者 |
| **Deep Audit** | **$1,900 / 次** | 完整 agent 系统（≤5 个服务）：配置 + 代码 + 运行时门禁建议；报告 + 策略落地 + 30 天复测一次；60 分钟评审会 | 已上生产、向客户/审计交代的团队 |
| Monitoring | **$299 / 月** | 季度复扫 + 报告更新 + 新发现邮件告警（SaaS 托管账本成熟后再升级） | 已做过审计的客户 |
| 企业定制 | 报价 | 私有化、BYOK、AIUC-1 核保包、陪同审计 | 保险/并购场景 |

定价逻辑：对标安全顾问日费（$800–$2,500/天）与合规工具年费；$490 是“不用开会就能批”的区间，$1,900 覆盖 1–2 人日。

## 3. 单位经济（单人）

- 自动化：`tools/audit_report.py` 生成 80% 报告内容（扫描、分级、证据、策略、签名、HTML 排版）；人工 30–60 分钟复核与写结论。
- Quick Audit：约 1.5 小时/单 → 时薪约 $300；每周 2 单 = 月 $3,900 左右。
- Deep Audit：约 1 人日/单 → 每周 1 单即月 $7,600。
- 获客成本：公开仓库体检 + 内容，现金成本≈0，时间成本为主要成本。
- 目标：**60 天内 5 单 Quick + 1 单 Deep ≈ $4,400**；90 天月流水稳定在 $5k 再考虑 SaaS。

## 4. 获客渠道（按优先级）

1. **公开仓库体检（冷启动主力）**：用 `tools/leadgen.py` 扫 MCP / agent 开源项目，产出报告；只联系“公开邮箱或明确欢迎安全报告”的维护者，附 opt-out。这是给价值、不是发垃圾邮件。
2. **GitHub 开源分发**：`agentproof-cloud` 已公开；补 README 徽章、`agentproof` CLI 在 PyPI 发布（需要用户做一次 `gh auth refresh -s workflow` 或本地 `twine`），让 `pip install agentproof` 可用。
3. **Show HN / Product Hunt**：等公网后端 + 英文界面就绪后发；现在发只会把流量送到半成品。
4. **MCP 生态目录与 awesome-list**：提交 scanner 到 MCP 安全工具列表（PR 而非广告）。
5. **内容 SEO**：3 篇高意图文章——“How to audit an MCP server config”“MCP security checklist”“Agent audit trail: logs vs signed receipts”；每篇底部放免费扫描 CTA。
6. **保险/合规渠道**：找 AI 责任险经纪做转介绍（他们需要技术尽调，我们出报告）。

## 6. 法律与信任边界（必须写进每份报告）

- 报告是**静态风险线索**，不是漏洞利用证明、合规认证或法律意见。
- 不做未授权的渗透、不执行目标代码、不访问私有仓库。
- 冷邮件必须可 opt-out；对明确拒绝者不再联系。
- 不宣称“AI Act 合规/SOC 2 认证”；只说自己能证明什么。
- 报告带签名摘要，客户可离线校验未被改动。

1. **收款**：注册 LemonSqueezy 或 Stripe，建 $490 / $1,900 / $299 三个价格，把支付链接给我（或直接放到报告 CTA）。

4. **披露边界**：确认冷邮件范围（只发公开仓库维护者？是否接受“未经请求的安全报告”）。
5. **部署后端（可选）**：给 Railway/Render token，我把 SaaS API 上公网；不给也能先卖审计。

## 9. 风险与退出条件

- 若 60 天内 0 单：说明“审计服务”需求不成立，转向纯开源 + 咨询/就业，不再投入 SaaS。
- 若客户只问不买：把报告价格降到 $190 试水，或改成“免费报告 + 修复实施收费”。
- 若大厂推出同类免费工具：保留 MIT 核心与离线验证差异化，转做“证据格式标准/插件”。
- 法律风险：所有材料保持“证据 ≠ 合规结论”的措辞；不代客户向监管提交。
