规则 MCP-02 · 来源 sample-dangerous-mcp.json

CRITICAL

2. MCP 服务以 shell 解释器 -c 方式启动，等价于任意命令执行

规则 MCP-03 · 来源 sample-dangerous-mcp.json

[shell] 命令字符串由模型或配置拼接，一旦可被影响就是远程命令执行。

bash -c npx -y mcp-server-shell@latest sk-***redacted*** 0

修复：改为可执行文件直接启动；确需脚本时固定参数、禁止拼接外部输入。

CRITICAL

3. 凭据以明文形式写在 mcp.json 的 env/headers 中

规则 MCP-05 · 来源 sample-dangerous-mcp.json

[shell] 环境变量 OPENAI_API_KEY 直接包含真实凭据；该文件通常随项目同步、备份、进日志。

"OPENAI_API_KEY": "sk-***redacted***"

修复：改用运行时注入的环境变量或密钥管理服务；mcp.json 中只保留 ${KEY} 占位符。

CRITICAL

4. 文件系统服务暴露了过宽的根目录

修复：把根目录收敛到项目内子目录，并配置只读 + 路径前缀校验。

CRITICAL

5. 数据库连接串内嵌明文口令

规则 MCP-10 · 来源 sample-dangerous-mcp.json

修复：使用 IAM/短期令牌或仅授予只读账号；口令放密钥服务，不放配置。
